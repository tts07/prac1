# Лабораторная работа: Экспресс-оценка рентабельности скважины (Вариант А)

**Выполнили:** Студенты с номерами 25 и 32 (N = 57)

## 1. Функциональная декомпозиция
1. `read_valid_param` — циклический запрос и валидация одного числа с границами.
2. `calc_oil_volume` — расчёт объёмного дебита нефти Qн = Qж * (1 - W / 100).
3. `calc_oil_mass` — перевод объёма нефти в тонны Mн = Qн * плотность / 1000.
4. `evaluate_profitability` — классификация статуса рентабельности через if-elif-else.

## 2. Блок-схема алгоритма
```mermaid
flowchart TD
    Start([Начало работы]) --> InputQ[/Ввод Qж и W с валидацией границ/]
    InputQ --> CheckValid{Значения в пределах?}
    CheckValid – Нет --> ErrMsg[/Вывод ошибки диапазона/]
    ErrMsg --> InputQ
    CheckValid – Да --> CalcVol[Расчёт объёма нефти: Qн = Qж * 1 - W/100]
    CalcVol --> CalcMass[Расчёт массы нефти: Mн = Qн * 850 / 1000]
    CalcMass --> Cond1{Mн < M_min?}
    Cond1 – Да --> Status1[Статус: Убыточна - стоп]
    Cond1 – Нет --> Cond2{Mн < 3 * M_min?}
    Cond2 – Да --> Status2[Статус: Рентабельна - база]
    Cond2 – Нет --> Status3[Статус: Высокодебитная - приоритет]
    Status1 --> Output[/Вывод сводки: Qн, Mн, Статус/]
    Status2 --> Output
    Status3 --> Output
    Output --> End([Конец работы])
